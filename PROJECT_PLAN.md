# Surya Live Studio

## Vision
Surya Live Studio is a professional Android live streaming application designed for creators, spiritual events, news channels and broadcasters.

## Main Features

- Live to YouTube
- Live to Facebook
- Live to Custom RTMP
- Multi Destination Live
- Professional Camera Controls
- 4K Streaming (device supported)
- Zoom
- ISO
- White Balance
- Manual Focus
- HDR
- Audio Noise Reduction
- Broadcast Graphics
- Lower Third
- Scrolling Ticker
- Transparent Overlay
- Custom Templates
- Sanskar TV Style Layout
- News Channel Layout
- Cloudflare Backend
- GitHub Source Control
